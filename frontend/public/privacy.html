Política de Privacidad

Última actualización: 30 de julio de 2026

1. Responsable

Esta aplicación es operada de forma independiente. No se recopila ni comparte información personal con fines comerciales.

2. Datos que recopilamos

  • Grabaciones de audio: Cuando usás el comando por voz, se envía una grabación al servidor para transcribirla a texto. El archivo de audio se elimina inmediatamente después de la transcripción.
  • Identificador de sesión: Un UUID aleatorio generado en tu navegador, almacenado en localStorage. No está vinculado a tu identidad real.
  • Nombres de temporizadores: Los textos que decís al crear un timer (ej. "pasta", "horno") se almacenan en la base de datos del servidor asociados a tu sesión.
  • Clave de API (opcional): Si configurás una clave de OpenAI en los ajustes, se almacena en la base de datos del servidor asociada a tu sesión.

3. Cómo procesamos los datos

El servidor utiliza el modelo faster-whisper de forma local para transcribir el audio. No se envía audio a servidores externos a menos que configures tu propia clave de API de OpenAI.

No se utiliza inteligencia artificial para analizar tus comandos más allá de la transcripción de voz y el parseo determinista por reglas.

4. Almacenamiento

Los datos se almacenan en una base de datos SQLite en el servidor. No se utiliza ningún servicio externo de base de datos ni almacenamiento en la nube.

Las claves de API se almacenan en texto plano en la base de datos (sin cifrado en reposo).

5. Servicios de terceros

  • OpenAI (opcional): Solo si proporcionás tu propia clave de API, los audios se envían a los servidores de OpenAI para su transcripción.
  • Notificaciones push: Se utiliza el servicio de notificaciones push de tu navegador (FCM para Chrome, APNS para Safari) exclusivamente para notificarte cuando un temporizador finaliza.
  • No utilizamos analytics, crash reporting, ni SDKs de terceros.

6. Tus derechos

Podés eliminar temporizadores individuales desde la interfaz de la app. Para eliminar todos tus datos asociados a una sesión, contactanos a la dirección de correo electrónico indicada abajo.
