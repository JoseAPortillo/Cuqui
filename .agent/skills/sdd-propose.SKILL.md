# sdd-propose SKILL

Purpose: create a concise change proposal describing intent, motivation, and high-level approach.

Template:
- Title
- Goal (one sentence)
- Background / Why
- Scope (in-scope, out-of-scope)
- Success criteria
- High-level approach and risks

Output:
- Proposal saved as `sdd/{change}/proposal` via `mem_save` (capture_prompt: false).

Guidance:
- Keep proposals short (<= 300 words) and include measurable success criteria.
